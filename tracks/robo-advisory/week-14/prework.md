# Prework — Predict Before the Recommendation Changes

Budget 20–25 minutes and work without generative AI.

1. Read `starter/scenarios.csv`. For Base, JobLoss, and LiquidityShock, predict which candidates
   pass every hard limit. State the expected direction before calculation.
2. For $500,000, a 6% gross annual return, and 10 years, calculate the first-year ending value
   under 0.25% and 0.90% annual fees. Do not yet extrapolate the ten-year difference.
3. Inspect `provider_compensation_bps`. Identify the candidate whose provider incentive creates
   the largest conflict question. A conflict flag is not proof of misconduct.
4. Write one sentence an AI explanation must never say because it would overstate certainty.
5. Run `python recommendation_audit_starter.py` only to verify access. Preserve the output or
   exact blocker and bring the offline page if needed.
