# Open Challenge — When a Higher Return Is Inadmissible

An AI argues that Growth is the best choice because its synthetic expected return is highest and
the client has a 12-year horizon. Without using AI, write the strongest version of that argument,
then defeat or qualify it using the mandate rather than opinion.

Next, change **one** defensible client fact—such as loss capacity, liquidity need, or equity cap—
without changing everything else. Predict the direction of the admissible set before running the
screen. Re-run the tests, explain every changed reason code, and state whether the recommendation
changes. If no candidate passes, defend escalation or a redesigned mandate instead of silently
relaxing a limit.

AI may then propose one additional scenario. Accept it only if it is decision-relevant, does not
invent client facts, and has an expected directional effect you state before execution. Close
with the fact most likely to reverse your conclusion and the person responsible for obtaining it.
