# Optional Open-Ended Challenge — The Same Label, a Different Valuation Object

Find one pair of values for your target company that share a familiar label but measure
different objects, periods, or conventions—for example cash, debt, shares, EBITDA, beta,
capital expenditures, or growth.

1. Cite both definitions and dates.
2. Reconcile the values mechanically when possible.
3. Place each value into the enterprise/equity/per-share architecture.
4. Show the direction of the error if the wrong value enters the model.
5. Ask both AI systems to explain the discrepancy, then grade their explanations against the
   source evidence.
6. Close AI and explain which value you would use, which you would retain as a sensitivity,
   and which you would reject.

The challenge earns no separate points. It may become evidence in Project 1 when it is
material, traceable, and owned by the student.
