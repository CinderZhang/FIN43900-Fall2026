# Studio 1 — Evidence Graph and Interface Audit

**Formative:** no grade item after Lab 24.

## Required work

1. State committee user, action/ask, and two genuinely connected components.
2. Complete one evidence-graph row per material claim.
3. Audit entity/date/currency/unit/frequency/price/scenario/weight/version interfaces.
4. Write expected direction and run one end-to-end changed-input test.
5. Ask AI for a contradiction/shared-dependency probe and independently verify it.
6. Repair, qualify, remove, or defer one affected claim.

## Exit evidence — Milestone 2

Evidence graph · interface-risk register · expected/actual end-to-end test · AI probe disposition ·
updated action/claim boundary · monitor/reversal trigger. If code fails, use frozen visible output
and trace the planned input path explicitly; do not claim an unexecuted result.
