# Changed-Input Return — Fresh Case, AI Closed

This 15-minute formative return probe asks whether you can independently transfer the course's
core habits to a fresh input. It creates no grade item and cannot substitute for or retroactively
repair missing capstone validation.
The instructor supplies the perturbation at the start; do not obtain it early.

## Protocol

1. **Predict (3 minutes):** with AI closed, write the expected direction of the finance output and
   action. Name the source fact, assumption, or interface that carries the change.
2. **Run (5 minutes):** change only the supplied input in the designated course case. Record the
   command, output location, units, and as-of state. Do not ask AI to edit or interpret the run.
3. **Reconcile (4 minutes):** compare predicted and observed direction. If they differ, locate the
   first broken assumption, unit, sign, date, or interface; do not rewrite the prediction.
4. **Decide (3 minutes):** state `ACTION HOLDS`, `ACTION CHANGES`, or `EVIDENCE INSUFFICIENT`, with
   one number and one reversal condition.

polished explanation cannot replace the preserved prediction or fresh run.
