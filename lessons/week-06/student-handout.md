# Week 6 Student Handout — Take It Apart, Then Present It

Last week: five years that balance and one value. This week: which assumptions carry that value,
what the price is paying for, and how you say it to a colleague.

## The rules

- Write the prediction before you run the change. A wrong prediction honestly reconciled is the point.
- Shocks do not add. Rerun the model for a named case.
- Posture is a conditional evidence test, never buy or sell.
- Every answer to a question carries a number from your own files.
- The page carries the check block and three review triggers tied to filings.

## DRIVER, one line each

Define — which assumptions carry the value, and what must be true for the price to be right?
Represent — the shock list and one named case. Implement — one request that reruns the model.
Validate — the ABG known answers, then your locked prediction against the result. Evolve and
Reflect — the page, the sceptic's questions, the panel.
