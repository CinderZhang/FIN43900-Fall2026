# Student Handout — Start Here

Follow this numbered path in the same order the Start Here module displays it:

1. Read **About Your Instructor** and **Welcome to FIN 43900**.
2. Optionally run the private **Orientation Audit** with its **Orientation Template**; it creates
   no grade or transmitted completion record.
3. Complete the ungraded **Entry Diagnostic and Recovery Router** with AI closed.
4. Download **Lab Environment Requirements** and **Project Environment Requirements**, then use
   **Course Environment Quickstart — Get One Evidence-Producing Run**. Use only the one named
   QuantEcon recovery page matching a diagnosed blocker.
5. Open **AI Access — Required Subscriptions and the Fallback Routes**; confirm both required subscriptions work. Then
   inspect **Week 1 — Dual-System Output Packet** so the no-account route is real before class.
6. Complete **Pre-Arrival Checklist**. Keep **AI, Data, and Credential Safety Card** and **Support
   and Communication Map** available throughout the course.
7. Before the first project checkpoint, read **Major Project Submission Architecture — Seven-Part
   Bundle**, **AI Boundary Card — Use This All Semester**, and **Starter Help Ladder — Learn
   Without Surrendering the Work**.
8. Open the **Week 1 — Technology Readiness, DRIVER & Company Screening** card. Read **Week 1 —
   Required Prework and Preparation** before downloading or running its readiness files.

Retain your local preflight command, first error or success output, Python version, and operating
system. The optional local **Orientation Audit** does not transmit completion and creates no grade.
