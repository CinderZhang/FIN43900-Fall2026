# AI, Data, and Credential Safety Card

- Never paste nonpublic student, employer, client, research, or licensed data into an AI tool.
- Never commit API keys, tokens, passwords, cookies, private URLs, or `.env` files.
- Use `.env.example` with empty named variables when credentials are required.
- Treat AI output as an unverified proposal; source-check facts and independently test code and
  financial logic.
- Record each AI access path and material use in the required validation/AI-use record. Include
  only model identifiers actually exposed by the interface; never claim a packet's collection
  tools as your own use.
- Preserve point-in-time evidence and as-of dates; do not replace historical values with later
  revisions without disclosure.
- If unsure whether data/tool use is permitted, stop and ask before uploading or sharing it.

Report an exposed credential immediately through the private course channel; do not post the
secret in the Q&A forum or a screenshot.
