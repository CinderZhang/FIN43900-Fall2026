# Optional Open-Ended Challenge — When the Terminal Value Owns the Model

Hold the current market price fixed and find two economically distinct assumption sets that
produce approximately the same per-share value.

1. One case must rely more heavily on explicit-period operating performance.
2. The other must rely more heavily on terminal assumptions.
3. Report terminal-value share, implied reinvestment logic, and the evidence burden of each.
4. Ask AI which case is “better,” then reject that framing: state which case is more
   supportable for this company and why.
5. Close AI and explain why a stable point estimate can hide unstable economic stories.

This is ungraded enrichment but may provide valid Project 1 sensitivity evidence.
