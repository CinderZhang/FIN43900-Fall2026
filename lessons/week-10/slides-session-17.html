I — the app, from one message

Minutes 8–30

Send this to your Lab 16 chat:

Build asof_app.py, a Streamlit app that works like a FRED page for interest rates. Get the data from FRED's public CSV downloads, no API key, one request per series: today's values from https://fred.stlouisfed.org/graph/fredgraph.csv?id=SERIES and the values as known on a date from https://alfred.stlouisfed.org/graph/alfredgraph.csv?id=SERIES&vintage_date=YYYY-MM-DD. A "." in the data is a missing day. Put the two downloads in two functions and cache them. Sidebar: a multiselect of series IDs with their names — BAA (Moody's Baa corporate bond yield), FEDFUNDS (federal funds rate), DGS10 (10-year Treasury yield), MORTGAGE30US (30-year mortgage rate), all four selected at the start; a text box to add any other FRED series ID; a start date (1 January 2020 at the start); an "as known on" date (today at the start). Page: one line chart per selected series, today's values from the start date, and under it the last date in the data known on the "as known on" date. Then one table, a row per series: the ID linked to its FRED page; the last date measured and its value as known on that date; the last date measured and its value today; how many values today's data has after the last date known then; how many values on the same dates have been revised since. An unknown ID shows an error for that series and the rest of the page still works. Under the title, one line: data from FRED and ALFRED, Federal Reserve Bank of St. Louis, downloaded today; built with AI help, a learning demonstration, not investment advice. Give me the command to run it.

Run it with the command your AI gave you. Expect: four rate charts and the table, as of today.
