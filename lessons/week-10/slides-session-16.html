The rules, in this order: (1) quarantine a row with no ticker; (2) remove an exact duplicate; (3) remove a row published after the decision date; (4) where one ticker and month has two publications, keep the latest one published by the decision date (a revision). The signal is the change in the index from the previous month to the latest knowable month.

I — build the filter from the instruction

Minutes 15–35

  1. Send this to your AI partner, then paste the table and the rules under it. The code it writes is yours: read it, run it, debug it.

Write one Python file, asof.py, standard library only. At the top, editable inputs: the table I paste below and a decision date of 2026-03-31. Apply my four rules in order and print the row funnel: for each rule, how many rows it removed and their row numbers. Print the as-of panel that remains. For each ticker print the signal: the percent change from the previous month to the latest month in the panel, to two decimals, naming that month. Then print a naive signal for comparison: the same calculation using every row's latest publication, ignoring the publication date. Compute everything from the inputs; never type an answer in. Give me the command to run it.
