# Formative Studio — Bond Evidence and Relative Value

This candidate studio creates no grade item.

## Required sequence

1. State institutional user, mandate, as-of boundary, and deeper-review decision.
2. Complete the off-cycle clean/accrued/dirty reconciliation without AI.
3. Validate K1 cash flows, PVs, price, duration, convexity, and +100 bp check.
4. Inspect every synthetic field and list unsupported real-market/credit inferences.
5. Freeze one transparent screen policy before seeing the ranked output.
6. Use AI to implement or red-team; preserve one accepted and one rejected/qualified claim.
7. Issue reject, quarantine, or deeper-review dispositions with reasons and missing evidence.

## One-page exit record

Decision frame · convention/known-answer reconciliation · screen rule and overrides · candidate
reason codes · staleness/liquidity caution · AI dispositions · evidence request · conditional
action · monitoring and reversal trigger.

Success means convention-consistent evidence and bounded judgment. Highest spread or model score
is not the success criterion. If code fails, complete the same record from the accessible table
and calculator path.
